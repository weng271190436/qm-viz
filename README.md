# qm-viz 🔬

Quantum mechanics visualizations — solving and plotting the Schrödinger equation.

Scripts for learning QM alongside Griffiths' *Introduction to Quantum Mechanics*.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Scripts

| Script | Griffiths Section | What It Shows |
|--------|-------------------|---------------|
| `finite_well_1d.py` | §2.6 | Finite square well: bound states, wavefunctions, transcendental equation |

## Resources

- Griffiths, *Introduction to Quantum Mechanics* (3rd ed.)
- [qmsolve](https://github.com/quantum-visualizations/qmsolve) — interactive QM solver
- [QuTiP](https://qutip.org) — quantum toolbox in Python
